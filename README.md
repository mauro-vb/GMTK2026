# Dynaminute

![Dynaminute](docs/media/dynaminute/logo.png)

**You will die in a minute. Get to the end before that!**

Dynaminute is a fast-paced platformer built for the **GMTK Game Jam 2026**. Each run gives you one minute on the clock, and every second lost or gained comes from how you play: grab time bonuses, dodge hazards, and race through hand-built levels before the timer runs out.

Play it on itch.io: **https://mauro-vb.itch.io/dynaminute**
